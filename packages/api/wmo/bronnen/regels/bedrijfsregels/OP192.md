# OP192 — Verzonden berichten moeten voldoen aan de technische eisen

## Definitie
Verzonden berichten moeten voldoen aan de voorgeschreven technische eisen voor formaat, codering en bestandsopbouw.

---

## Samenvatting
Deze bedrijfsregel bepaalt aan welke technische specificaties iWmo-berichten moeten voldoen voordat zij verzonden mogen worden.

De regel waarborgt uniforme verwerking van berichten binnen de iWmo-standaard.

---

## Regel
Verzonden berichten moeten voldoen aan de volgende technische eisen.

---

## Technische eisen

| Eigenschap | Waarde |
|---|---|
| Formaat | XML |
| Codering | UTF-8 |
| Byte Order Mark (BOM) | Niet toegestaan |
| Einderegel | CR/LF |
| Bestandsextensie | .xml |

## Toepassing
Deze regel is relevant bij:
- genereren van iWmo-berichten
- technische validatie van berichten
- XML-bestandscontrole
- uitwisseling van berichten tussen systemen
- verwerking van WMO301-, WMO305-, WMO307-, WMO315-, WMO317-, WMO319-, WMO323- en WMO325-berichten
