## Structuur voor de chatbot

Voor RAG/FAQ-gebruik is dit indexbestand bedoeld als **navigatiebestand**. De afzonderlijke artikelbestanden bevatten de inhoud van de betreffende bepalingen.

Bij een vraag naar alleen een artikeltitel kan de chatbot dit indexbestand gebruiken. Bij een inhoudelijke vraag moet het bijbehorende artikelbestand als primaire bron worden gebruikt.

**Bron:** Overeenkomst Maatwerkvoorzieningen maatschappelijke ondersteuning, versie 1.3.
