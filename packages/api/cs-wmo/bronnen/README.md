# Kennisbank Contractstandaarden Wmo – RAG – versie 1.3

## Doel
Deze kennisbank is ingericht voor een chatbot/RAG over de Contractstandaarden Wmo.

## Bronlagen

### 01_contractteksten
De actuele primaire teksten van versie 1.3.
Gebruik deze map voor vragen als:
- Wat staat er in artikel X?
- Welke bepaling geldt?
- Wat is de actuele tekst?

### 02_toelichtingen
De toelichtingen zijn bewust gescheiden van de contractteksten.
Gebruik deze map voor:
- Waarom is een artikel opgenomen?
- Wat is de bedoeling van een bepaling?
- Wat is de ratio/achtergrond?
- Welke aandachtspunten noemt de toelichting?

De afzonderlijke artikelbestanden in `overeenkomst/` zijn retrieval-eenheden; de volledige toelichting blijft daarnaast als bronbestand beschikbaar.

**Let op:** toelichting is geen contracttekst.

### 03_wijzigingen_1.2_naar_1.3
Gebruik deze map voor vragen over veranderingen tussen versie 1.2 en 1.3.

### 04_faq
Gebruik deze map voor veelgestelde vragen en praktische vraagformuleringen.

### 05_metadata
Bevat routerings- en manifestinformatie voor de kennisbank.

## Bronhiërarchie

1. Actuele primaire contracttekst versie 1.3
2. Was-Wordt 1.2 → 1.3 voor wijzigingsvragen
3. Toelichting versie 1.3 voor ratio en bedoeling
4. FAQ voor praktische formuleringen
5. Samenvattende verschilkennisbank als aanvullende bron

## Antwoordregels

- Geef eerst een kort, direct antwoord.
- Noem het relevante artikel of onderdeel.
- Gebruik de primaire bron voor letterlijke actuele contracttekst.
- Gebruik Was-Wordt voor de vaststelling van wijzigingen.
- Gebruik de toelichting voor waarom/bedoeling.
- Maak van een toelichting geen contractuele verplichting.
- Behandel optionele bepalingen als optioneel.
- Voeg geen juridische interpretatie toe die niet door de bronnen wordt gedragen.
- Als de bronnen geen antwoord geven, zeg dat.
