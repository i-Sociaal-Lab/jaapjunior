### Brontekst van de toelichting

Ratio:

-   Veel gemeenten kennen beleid voor social return on investment. Dat
    beleid willen zij ook toepassen bij de inkoop van maatschappelijke
    ondersteuning.

-   Het is niet mogelijk gebleken een bepaling voor social return on
    investment te standaardiseren. Daarom legt de contractstandaard
    alleen de vindplaats voor deze bepaling vast.

Inhoud:

-   De gemeente bepaalt zelf hoe zij social return on investment
    verwerkt in de overeenkomst. Dat moet wel op deze plek.
